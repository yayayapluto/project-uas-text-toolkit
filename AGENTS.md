# Agent instructions

## Agent skills

### Issue tracker

Issues dilacak sebagai file markdown lokal di `.scratch/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Lima label default: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` di root + `docs/adr/`. See `docs/agents/domain.md`.
